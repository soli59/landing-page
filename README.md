# Landing Page Project

This project is part of The Odin Project curriculum.  
It’s a simple and clean landing page built using HTML and CSS.  
The goal is to practice Flexbox, create a balanced layout, and understand how to structure a web page.

---

## What I Learned
- Building layouts using Flexbox  
- Using semantic HTML tags like header, div, and footer  
- Styling text, buttons, and containers with CSS  
- Aligning and spacing elements for better design  
- Adding and handling images properly  

---

## Features
- Responsive layout  
- Hero section with call to action  
- Information cards  
- Quote section  
- Simple footer  

---

## Technologies Used
- HTML5  
- CSS3 (Flexbox)
